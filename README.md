## Описание

Репозиторий содержит решение 11 базовых задач на синтаксис Python
(числа, строки, списки, кортежи, множества, словари), инкапсулированных
в отдельные модули, а также верхнеуровневый модуль `main.py` с
консольным меню для запуска заданий по отдельности или всех сразу.

## Структура проекта
├── 00_distance.py # Расстояния между городами
├── 01_circle.py # Площадь круга и проверка точек
├── 02_operations.py # Расстановка арифметических знаков
├── 03_favorite_movies.py # Срезы строки фильмов
├── 04_my_family.py # Семья и рост
├── 05_zoo.py # Операции со списком животных
├── 06_songs_list.py # Время звучания песен Depeche Mode
├── 07_secret.py # Расшифровка секретного сообщения
├── 08_garden.py # Множества цветов (сад и луг)
├── 09_shopping.py # Минимальные цены в магазинах
├── 10_store.py # Складские запасы и стоимость
├── main.py # Консольное меню запуска заданий
├── tests/
│ └── test_tasks.py # Pytest-тесты для всех модулей
├── requirements.txt # Зависимости проекта
└── README.md

## Установка

1. Клонировать репозиторий:

   ```bash
   git clone https://github.com/mlakusss/Lab1_python.git
   cd Lab1_python
2. (Опционально) создать и активировать виртуальное окружение:
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
3. Установить зависимости:
pip install -r requirements.txt

## Запуск
Отдельное задание

   python 01_circle.py

Через консольное меню

   python main.py

Меню позволяет выбрать конкретное задание (0–10), запустить все задания
сразу (a) или выйти (q).

## Тестирование
Проект покрыт pytest-тестами. Запуск:

   pytest -v

Тесты проверяют корректность работы каждого модуля-задания
через перехват стандартного вывода (capsys).
